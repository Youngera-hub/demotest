# 人格透镜 TraitLens

> 三个可以直接部署到 GitHub Pages 的人格 / 性格 / 职业兴趣测评。题目公开、计分公式公开、常模表随仓库分发，**答案只留在访问者的浏览器里**。

## 为什么不是又一个 MBTI 网站

网上多数「性格测试」把结果压成一个标签就结束。本站把**连续维度放在前面**：

- 每个维度给的是**百分位**而不是分数，并按年龄常模换算——你能看到自己在同龄人里的位置，而不是一个无参照的「82 分」。
- 五维之下还有 **30 个侧面**。总分居中但侧面两极分化的情况非常常见，只看五维会漏掉它。
- 四字母类型是**同一批数字的另一种读法**，不是第二套测量，所以每条轴旁边都标出它离中点有多远；接近中点时会显示「接近中点」而不是假装结论很稳。
- 结果页会直接告诉你哪两个维度分离度最大、哪些维度组合值得注意，而不是给一段放在谁身上都准的话。

## 计分方法

反向题先按 `6 − x` 翻转，然后：

```
侧面分  = 4 道题之和                      （区间 4–20）
域分    = 6 个侧面之和                     （区间 24–120）
T 分    = 50 + 10 · (原始分 − μ) / σ       （μ、σ 取自对应年龄区间常模）
百分位  = c₁ − c₂T + c₃T² − c₄T³           （T 超出常模区间时截断为 1 / 99）
```

- 题库、键位表（哪 55 道题反向计分）与常模表全部来自 [`five-factor-e`](https://github.com/NeuroQuestAi/five-factor-e)（MIT），由 `research/dump.py` 从上游导出，再经 `research/gen_big5.py` 生成为 `assets/js/data-big5.js`。**不要手改这个文件**，改题库请重新跑生成脚本。
- 常模按 12–20 / 21–40 / 41–60 / 61+ 四个年龄区间分桶；不填年龄时取四个桶的平均值，页面上会明确标注这是近似值。

### 计分正确性校验

```bash
python research/crosscheck.py   # 用上游库对 8 组随机答案生成基准结果
node dev/verify.mjs             # 比对本站 JS 的键位与 280 个百分位
```

当前状态：`PASS — 8 组随机答案：键位 120/120 一致，280 个百分位与 five-factor-e 参考实现一致（容差 0.6）`。改动计分逻辑后必须重跑这两条命令。

## 本地运行

纯静态站点，没有构建步骤，任何静态服务器都行：

```bash
python -m http.server 8123     # 或 npx serve .
# 打开 http://127.0.0.1:8123
```

## 部署到 GitHub Pages

1. 新建仓库并把本目录推上去（`main` 分支）。
2. 把 `assets/js/config.js` 里的 `REPO` 和 `index.html` 里的 `<link rel="canonical">` 换成你自己的仓库 / Pages 地址。
3. **Settings → Pages → Build and deployment**：Source 选 `Deploy from a branch`，Branch 选 `main` + `/ (root)`，保存。
4. 一分钟后访问 `https://<你的用户名>.github.io/<仓库名>/`。

仓库里已带 `.nojekyll`（跳过 Jekyll 处理，保证 `_` 开头的文件不被吞）和 `404.html`（子路径直接访问时跳回首页，因为本站用 `#/` 哈希路由）。

```

```

## 设计取舍

- **零依赖、零构建**：没有框架、没有 CDN、没有埋点。整个站点就是一次 HTML + 一次 CSS + 几个 ES 模块，离线也能跑。
- **不上传任何东西**：没有后端，答案与结果只写 `localStorage`；结果卡 PNG 由本地 Canvas 生成。
- **可复现**：题库、键位、常模、公式全部在仓库里，任何人可以重算同一份答案得到同一个数。

## 已知局限

- 自陈量表受当下状态、社会期许与题意理解影响，一次测量的解释力有限。
- 常模来自公开研究样本，与中文使用人群分布并不完全一致，百分位应视为近似定位。
- 类型标签会随小分差翻转；请优先读连续维度与侧面，而不是记住四个字母。
- 本站是自我探索工具，**不构成心理学诊断**，也不能替代专业评估与干预。

## 隐私

不收集、不传输任何个人信息。年龄为可选项，仅用于选择常模区间，保存在本机。清空浏览器站点数据即可彻底删除全部记录（页面内也有「清空全部记录」按钮）。
